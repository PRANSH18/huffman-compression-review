# Huffman Coding for Image Compression: A Critical Review

**A review of how Huffman encoding compresses images, where it works well and where it falls short.**

## What it covers

- Why image compression matters for storage and transmission
- How Huffman coding works: a greedy, lossless method that gives the most frequent symbols the shortest codes, with the prefix rule preventing ambiguity on decoding
- Strengths and limits against alternatives such as arithmetic coding
